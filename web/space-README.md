# RouteX

A C++ logistics system built for a Data Structures and Algorithms course:
FIFO order queue, hash-table shipment lookup, weighted city graph with
heap-based Dijkstra for the fastest route, and a SHA-256 linked-list
blockchain for tamper-evident shipment history.

The C++ backend is compiled to WebAssembly and runs in your browser.
Shipments you add are kept in this browser only.

Source code: https://github.com/AhmedMustafa-0817/RouteX
