INTERACTIVE LAB

How Tampering Detection Works

Experience cryptographic immutability powered by SHA-256 and custom C++ linked lists.

1
Valid State

Every block's SHA-256 digest is calculated from its index, timestamp, previous hash, and transfer events. Verification recalculates every hash and confirms a match.

2
Simulate Tamper

Clicking Simulate tampering changes an event field (such as destination city) in memory without recalculating block hashes, mirroring an unauthorized database edit.

3
Immediate Detection

Verification detects the mismatch between the block's declared hash and the recalculated SHA-256 digest, identifying the compromised block and aborting verification.

4
Restore & Re-verify

Restoring integrity reverts the altered data. Verification immediately succeeds again with zero discrepancies.
